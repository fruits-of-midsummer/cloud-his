# REST 接口说明

统一前缀 `/api`，JSON 字段 snake_case，人民币分为整数。成功返回数据本身；错误返回 `{ "message": "可读错误" }`。400 参数错误，401 未登录，403 无权限或 CSRF 失败，404 数据不存在，405 请求方法不支持，409 状态/并发冲突，429 登录限流，500 附内部参考号。

所有业务接口要求登录。除 GET 外，须携带 `X-CSRF-Token`，先从 `GET /auth/session` 获取 `csrf_token` 及 Cookie。登录成功后 token 会轮换，客户端必须保存响应的新 token。跨站请求未开放 CORS。

| 方法与路径 | 岗位 | 说明 |
| --- | --- | --- |
| GET /health | 公共 | 数据库及应用健康状态 |
| GET /auth/session | 公共 | 当前用户和 CSRF token |
| POST /auth/login | 公共 | username / password |
| POST /auth/logout | 全部 | 注销会话 |
| POST /auth/password | 全部 | old_password / new_password；成功需重登 |
| GET /catalog | 全部 | 科室、有效人员、医技目录和药品 |
| GET /dashboard | 全部 | 当前岗位可见统计与最近记录 |
| GET /schedules?start=&end= | 全部 | 最多63天排班范围，默认当天 |
| GET /diseases?q= | 医生 | 疾病名称和编码查询，最多100条 |
| GET /patients?q=&page=&size= | 收费员 | 主档姓名/病历号查询 |
| POST /patients | 收费员 | 创建患者主档，服务端生成 case_no |
| POST /registrations | 收费员 | patient_id / schedule_id / book_requested / pay_method / received_cents / request_key |
| GET /encounters?q=&page=&size= | 收费员、医生 | 医生只返回本人就诊 |
| GET /encounters/{id} | 收费员、本人医生 | 就诊、项目、收费单、退款；病历正文仅本人医生 |
| POST /encounters/{id}/cancel | 收费员 | reason；未诊退号并退费 |
| PUT /encounters/{id}/record | 本人医生 | 病历字段、initial_diagnosis、version（新建0） |
| POST /encounters/{id}/diagnosis | 本人医生 | disease_code / disease_name / opinion |
| POST /encounters/{id}/finish | 本人医生 | 业务完成后结束就诊 |
| POST /orders | 本人医生 | encounter_id / item_ids[] / purpose / body_part / notes |
| POST /prescriptions | 本人医生 | encounter_id / items[]；每药包含 medicine_id / quantity / drug_usage / dosage / frequency / days / notes |
| POST /orders/{id}/cancel | 本人医生 | reason；只撤销未收费未执行项 |
| POST /charges | 收费员 | encounter_id / order_ids[] / pay_method / received_cents / request_key |
| GET /invoices/{id} | 收费员、本人医生 | 含明细的收款凭证 |
| POST /orders/{id}/refund | 收费员 | reason；按原收费明细全额退费 |
| GET /orders?kind=&q=&page=&size= | 对应医技或药房 | CHECK / LAB / TREAT / DRUG；医技按科室过滤 |
| POST /orders/{id}/register | 对应医技 | executor_id；医生岗位及科室必须匹配 |
| POST /orders/{id}/result | 分配的执行人员 | content；不允许覆盖结果 |
| POST /orders/{id}/dispense | 药房 | 已缴费未发药项目 |
| POST /orders/{id}/return | 药房 | reason；整项退药回库 |
| POST /stock/in | 药房 | medicine_id / quantity / reason |
| GET /stock/movements?q=&page=&size= | 药房 | 姓名、病历号、药品编码或名称检索 |
| GET /admin/users | 管理员 | 账号列表，不包含密码哈希 |
| POST /admin/users | 管理员 | username / display_name / role_code / department_id / password |
| PUT /admin/users/{id}/active | 管理员 | active；不能停用自己 |
| POST /admin/departments | 管理员 | code / name / kind |
| POST /admin/schedules | 管理员 | doctor_id / visit_date / period / level_name / fee_cents / quota |
| POST /admin/items | 管理员 | 项目编码、名称、类别、规格、价格、科室 |
| PUT /admin/items/{id} | 管理员 | 修改目录，不追溯改价 |
| POST /admin/medicines | 管理员 | 药品目录（新增库存为0） |
| PUT /admin/medicines/{id} | 管理员 | 修改药品，不追溯改价 |
| PUT /admin/catalog/{item或medicine}/{id}/active | 管理员 | active；停用目录 |
| GET /admin/audit?page=&size= | 管理员 | 审计分页 |

管理员拥有上述配置和支持权限；临床数据权限在后端强制执行。分页响应为 `{ items, total, page, size }`，size 最大100。搜索长度最大100字符；同源 Cookie 会话30分钟无操作过期。

收费示例：

```json
{
  "encounter_id": "就诊ID",
  "order_ids": ["待收费项目ID"],
  "pay_method": "现金",
  "received_cents": 5000,
  "request_key": "客户端为本次收费生成的唯一UUID"
}
```

浏览器端先查看返回金额，不应自行决定项目单价。发生请求超时需要重试时应沿用相同 request_key；不要立即生成新收费请求。
